# Student-Grade-Calculator
Vityarthi Project
A simple Python program that calculates the total marks, average marks, and grade of a student based on marks obtained in five subjects.

Features

Stores marks for five subjects.

Calculates total marks.

Calculates average marks.

Assigns a grade using if-elif-else conditions.

Displays the appropriate grade.

Technologies Used

Python 3

How It Works

Marks for five subjects are stored in variables.

The program adds all five marks to calculate the total.

The total is divided by 5 to calculate the average.

The average is compared with different grade ranges.

The final grade is displayed.

Example

Input

Subject 1: 44
Subject 2: 67
Subject 3: 76

Subject 5: 58

Output
